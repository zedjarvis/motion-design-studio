# Public assets and license boundaries

MIT applies to original studio code, authored diagnostic artwork and repo-owned
skills. It does not relicense dependencies, fonts, music, product identity,
reference artwork or captured interfaces.

| Included material | Terms / provenance |
| --- | --- |
| Original TypeScript/React/Python/Node code and skills | MIT, LICENSE |
| Seeded diagnostic paint-stroke PNG | Authored by this studio; MIT; generator/provenance retained |
| Inter, Roboto Mono, Bodoni Moda, Manrope, Pacifico fonts | SIL OFL 1.1; full notices beside font files |
| Happy Beats / Business Moves volumes 9, 10, 12 | Sascha Ende, CC BY 4.0; public/audio/CREDITS.txt and ledger.json |
| Kenney interface/impact/casino SFX | CC0; public/audio/ledger.json |
| Original generated Creators transition SFX | Authored synthesis; provenance in its assets/sfx directory |
| Geographic land arrays | Natural Earth public domain; source in the Minimalist provenance |
| JavaScript dependencies | Their individual licenses; THIRD_PARTY_NOTICES.txt and installed packages |

p5 is LGPL-2.1, while p5.brush, Thinking Orbs, Rough.js, Anime.js and PixiJS use
MIT. The package code is not vendored or modified. Remotion uses its own license;
review its [official terms](https://www.remotion.dev/docs/license) for your use.

The public repository excludes product screenshots/branding, stock/product
photos, recovered benchmark imagery, downloaded reference videos and publisher
research-image copies where redistribution terms have not been established.
Their filenames/provenance may be retained to document an optional example;
this does not grant rights to those files. Obtain appropriate rights and restore
them locally before rendering the affected examples. The self-contained
EngineCheck, GraphicsCapabilities and CursorProbe diagnostics need none of them.

The cursor research links original publisher imagery and published demonstration
footage. Local research copies remain ignored. They are never cursor assets or
inputs to the delivered Schoolbooks film; its vector glyphs are authored here.

Raw product repository excerpts, machine paths, voice outputs, generated reports
and finished exports are local-only. A public clone has no private product repo,
demo credentials or customer data. Set external repo paths using environment
variables or .studio.local.json (ignored), for example:

```json
{"repositories":{"SCHOOLBOOKS_REPO":"/path/to/schoolbooks"}}
```

Keep full font licenses and music attribution when redistributing licensed
assets or films. Exact benchmark comparisons and local product films remain
separate from the MIT software grant.
